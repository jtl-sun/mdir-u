# mDIR Project Direction

## Identity

mDIR-U is the Linux/Ubuntu edition of a modern dual-pane file manager inspired by the directness and accessibility of DOS-era Mdir-style workflows. It is not intended to replace or claim the historical Mdir III identity.

## Version policy

- Keep public mDIR-P and mDIR-U versions in the **V2.xx.xx** series.
- Do not move the project to V3.x.
- Continue future updates by increasing the minor/patch components inside V2.

## Platform goals

1. Make file management easier for users who find Linux file workflows inconvenient.
2. Keep mDIR-U natural in Ubuntu and modern terminal environments.
3. Keep the Windows companion mDIR-P comfortable in Windows Terminal and PowerShell.
4. Preserve keyboard-first speed while keeping mouse operations intuitive.
5. Keep dual-pane independence and predictable file-operation safety.

## Modern core features

- **AI/File**: contextual AI assistance without turning the file manager into an AI-only interface.
- **File View / Preview**: fast viewing of images, PDF and Office documents without unnecessary application switching.
- **File Search**: fast search, indexing and discovery as a first-class file-management workflow.

## UX principle

Features should be discoverable at a glance, fast from the keyboard, and usable with one obvious mouse action. New visual features must not reduce selection clarity, file-operation safety, Linux portability or large-folder performance.

## old_M_tema

`old_M_tema` is a visual homage to classic DOS file-manager readability: black workspace, cyan/teal chrome, strong cursor contrast and extension-specific colors. The modern mDIR-U layout, AI/File, Preview, Search, terminal thumbnails and progress system remain unchanged.
